# mangadex-dotnet-cli
A MangaDex cli client built with .NET and the MangaDex API


## Attributions

This project uses the [MangaDex API](https://api.mangadex.org/docs/) to search
and retrieve manga data. All manga content, artwork, and translations remain
the property of their original creators and the scanlation groups who
translated them.

- **Data & imagery source:** [MangaDex](https://mangadex.org)
- **Chapter translations:** Credited individually per chapter — the specific
  scanlation group responsible for each chapter is displayed in the CLI output
  and saved alongside any downloaded content (see `ATTRIBUTION.txt` in each
  chapter's download folder).

This project is not affiliated with or endorsed by MangaDex. It is an
independent, third-party client built using their public API in
compliance with their [Acceptable Use Policy](https://api.mangadex.org/docs/).

## Legal & Ethical Notes

- This tool uses only MangaDex's official public REST API.
- It is a personal/educational project, not a commercial product. It does not
  run ads and is not monetized in any form.
- It complies with MangaDex's Acceptable Use Policy, including attribution
  requirements for MangaDex and individual scanlation groups.
- Downloaded content is for personal offline reading only and is not
  redistributed by this tool.
